# Scratch-JavaFX

Application desktop de programmation visuelle inspirée de Scratch, développée en Java et JavaFX avec une architecture MVVM.

## Présentation

Cette application permet de construire visuellement un programme à partir d'actions, puis de l'exécuter dans un environnement graphique.

Le projet a été initialement réalisé en groupe dans le cadre de mon Bachelier en Informatique de gestion à l'EPFC.

Après la version réalisée en groupe, j'ai repris et approfondi individuellement le projet afin de mieux maîtriser son architecture et son fonctionnement, notamment dans le cadre de ma préparation aux examens.

## Fonctionnalités principales

- Construction d'un programme à partir d'actions
- Exécution des instructions dans un environnement graphique
- Gestion et enchaînement des actions
- Actions de déplacement et de dessin
- Boucles et répétition d'actions
- Gestion du stylo
- Sauvegarde et chargement des programmes dans des fichiers texte
- Gestion des erreurs lors de l'exécution
- Fonctionnalités supplémentaires développées individuellement, notamment le dessin de rectangles et de polygones ainsi que la téléportation

## Technologies utilisées

- Java
- JavaFX
- Maven
- Architecture MVVM
- Git

## Évolution du projet

La première version de l'application a été développée en groupe.

J'ai ensuite repris le projet individuellement afin d'en approfondir le fonctionnement et de refactoriser une partie de son architecture MVVM. J'ai également réimplémenté et ajouté plusieurs fonctionnalités dans le cadre de ma préparation aux examens.

Le dépôt conserve l'historique Git de ces différentes étapes du développement.
